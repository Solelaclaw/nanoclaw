# SDR — outbound prospecting workflow

See `instructions.md` for the operating procedure.

This skill is always active for SoleLaClawde PRO (B2B) groups. The rep's
Gmail and Calendar are connected via OneCLI; Apollo handles prospect
search and enrichment. Drafts are stored in the SoleLaClawde pipeline
(Campaigns table) and surfaced for the rep's batch review before any
send happens. The rep is the only approver — the agent never sends
without an explicit human "approve" signal.
